# 💻 Ziad Portfolio

A modern and dynamic personal portfolio website built with Laravel 12.
The project combines a professional portfolio frontend with a protected dashboard
that allows the portfolio owner to manage website content dynamically.

## 📌 Project Overview

Ziad Portfolio is designed to present professional information, services,
skills, projects, and contact information through a modern dark-themed interface.

The project includes a content management dashboard, allowing the owner to
update portfolio content without directly modifying the source code.

## ✨ Main Features

- 🏠 Dynamic Home section
- 👤 About Me section
- 🛠️ Services management
- 💼 Projects management
- 📊 Skills management
- 🔗 Social media links management
- 📩 Contact form
- 💬 Contact messages management
- 🔐 User authentication
- 📋 Protected admin dashboard
- 🖼️ Image upload and management
- ✏️ Dynamic content editing
- 📱 Responsive user interface
- 🌙 Modern dark portfolio design
